## Analysis

The `analysis/` directory contains Jupyter notebooks (`.ipynb`) with detailed experimental analyses and intermediate results. These notebooks provide a more granular view of the simulations compared to the final report.

- `01_baseline.ipynb` – contains the initial exploratory analysis.  
  The preliminary results suggested that the environmental change rate parameter $c$ does not have a strong or consistent impact on speciation.

- Based on these observations, a more detailed and systematic investigation was conducted in `01_report.ipynb`, which includes a broader parameter sweep, statistical analysis, and more rigorous evaluation of speciation dynamics.

- The final `report.pdf` represents a concise synthesis of the most important findings from the analysis. It summarizes the methodology, key experiments, and main conclusions, serving as the high-level overview of the project.

In summary:
- notebooks → detailed computations and experiments  
- `01_baseline.ipynb` → exploratory analysis motivating further study  
- `01_report.ipynb` → comprehensive and systematic analysis  
- `report.pdf` → distilled final conclusions and results
